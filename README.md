# Эмулятор оболочки
Консольная программа с приглашением вида `vfs:имя>`. Команды вводятся с клавиатуры или читаются из стартового скрипта.
## Сборка
Откройте решение в Visual Studio и соберите конфигурацию Debug, платформа x64.
Готовый файл: `x64/Debug/REPL.exe`.
## Запуск
Из папки решения:
```text
x64\Debug\REPL.exe --vfs from-cli --script smart.txt --config config.yaml
```
Можно запустить `run_ok.bat` из той же папки.
## Параметры
| Параметр   | Назначение                          |
|------------|-------------------------------------|
| `--vfs`    | Имя VFS. Попадает в приглашение.    |
| `--script` | Файл со стартовыми командами.       |
| `--config` | Файл конфигурации YAML.             |
В `config.yaml` допустимы ключи `vfs` и `script`. Если ключ задан и в командной строке, и в файле, используется значение из файла.
Пример:
```yaml
vfs: from-file
script: smart.txt
```
При старте программа печатает итоговые пути.
## Команды
- `ls` и `cd` пока выводят своё имя и аргументы.
- `echo` печатает аргументы. Без аргументов сообщает, что вывод включён.
- `exit` завершает работу.
- Неизвестная команда даёт сообщение `Undefined command`.
- В строке раскрываются переменные окружения: `$OS`, `$ИМЯ`.
## Стартовый скрипт
В файле скрипта каждая строка — одна команда. Программа показывает приглашение и строку, затем результат. Ошибочная строка не останавливает скрипт. `exit` прекращает и скрипт, и программу.
Если скрипт или конфигурация не открываются, печатается сообщение об ошибке.
